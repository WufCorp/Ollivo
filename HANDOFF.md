## 1. Что это и для кого

Десктоп-программа для Windows: человек без технических знаний ставит её, выбирает модель
и разговаривает с ней. Дальше — картинки, видео, голос, файлы. Всё считается на его ПК,
переписка никуда не уходит; сеть нужна только чтобы скачать модель или движок.

Целевой пользователь — не разработчик. Он не знает слов «квантизация», «контекст», «сэмплер».
Это главное ограничение всех решений: если что-то нельзя объяснить одной понятной фразой,
оно не попадает в простой режим.

Конкуренты и чем отличаемся: ComfyUI (мощно, но сложно), LM Studio / Jan / Ollama (только текст),
Pinokio (установщик, а не единое окно), Stability Matrix, Fooocus, Msty. Ollivo — одно окно
на все виды моделей плюс «всё настроится само».

MVP: **только Windows + NVIDIA**. AMD, Intel и macOS — после 1.0.

Название: **Ollivo**, сайт ollivo.ru. Идентификатор приложения `ru.ollivo.app`,
папка установки по умолчанию `<диск>\Ollivo`, префикс в S3 — `ollivo/`.

## 2. Как запустить и проверить

Нужны Node.js 22+ и стабильный Rust.

```bash
npm install
npm run tauri dev
```

```bash
npm run tauri build
```

```bash
cargo test --manifest-path src-tauri/Cargo.toml
```

Сейчас 127 тестов проходят, 24 помечены `#[ignore]` — им нужны сеть, настоящие модели
или запущенный движок. Самые полезные из них:

```bash
cargo test --manifest-path src-tauri/Cargo.toml catalog::tests::real_picks -- --ignored --nocapture
```

- `probe::tests::real_models` — разбор настоящих GGUF и safetensors со «светофором»;
- `catalog::tests::real_picks` — как выглядит подборка на этом железе;
- `catalog::tests::real_search` — живой поиск по HuggingFace;
- `llm::tests::real_chat_stream` — стриминг на запущенном llama-server;
- `llm::tests::real_human_paths`, `speech::tests::real_human_paths` — чат и голос, когда в путях
  кириллица и пробелы («…\Иван Петров\Ollivo данные\…»), а VC++ — только наши копии; вместо проверки в ВМ;
- `llm::tests::real_roles` — роли и манеры ответа на Qwen2.5 3B;
- `llm::tests::real_project` — папка проекта на Qwen3.5 2B: читает файлы, создаёт с разрешения,
  правит куском, удаляет в «Авто» с историей, в «Плане» ничего не меняет;
- `tests::real_out_of_memory_then_lighter`, `llm::tests::real_context_overflow` — понятные ошибки на настоящем движке;
- `update::tests::published_update_real` — описание версии и подпись из S3;
- `chats::tests::search_speed` — скорость поиска по 500 разговорам (запускать с `--release`).
- `media::tests::real`, `engines::tests::ffmpeg_7z_real` — ffmpeg: HEIC, AVIF, M4A, OPUS, видео;
  распаковка настоящего 7z (пути к файлам — в переменных окружения, см. комментарии тестов).

Пути с настоящими моделями в тестах зашиты как `D:\Ollivo\models\…` — на другой машине
их надо поменять.

⚠️ `download::tests::without_range_support` один раз падал и потом проходил три полных
прогона подряд. Похоже на гонку в тестовом HTTP-сервере, не в коде загрузок. Если
повторится — смотреть `testserver.rs`.

### Где что лежит у пользователя

```
%APPDATA%\ru.ollivo.app\     settings.json, models.json, chats\<id>.json, problems.log,
                             attachments\ (картинки), backups\ (файлы проекта до замены
                             и удаления моделью, 30 дней; уборка — при запуске)
<диск>\Ollivo\               папка данных (диск выбирает мастер)
  engines\<id>\<версия>-<сборка>\   движок + метка ollivo.json + ollivo.files.json
  models\<автор>\<репозиторий>\     скачанное из каталога
  downloads\                        архивы движков и недокачанное
  logs\<движок>.log                 + .prev.log
```

Секретов в файлах нет. Пароль прокси, токен HuggingFace и пароль ключа подписи —
в диспетчере учётных данных Windows (крейт `keyring` 3, `windows-native`).
Ключ подписи обновлений — `~\.tauri\ollivo.key`, его пароль — запись `ollivo-updater-key`.
**Потеря ключа = обновления не встанут ни у кого.** Нужна копия.

## 4. Принятые решения и почему

Их не надо переигрывать заново — за каждым стоит замер или разбор.

| Решение | Почему |
|---|---|
| Tauri 2 + React вместо Electron | установщик ~10 МБ против ~150, нативное окно |
| Главный бэкенд — Rust-ядро, не Python | логика установки должна работать до того, как Python появился. Раньше планировали Python-сайдкар на FastAPI — отменено |
| Python (uv + свой 3.12) только для ComfyUI, по требованию | чат должен работать через 5 минут после установки, без 5 ГБ torch |
| Движок чата по умолчанию — Vulkan-сборка llama.cpp | 30 МБ против ~600 у CUDA, не нужны библиотеки CUDA, на GTX 1080 ещё и в 1,5 раза быстрее генерирует. CUDA — необязательный ускоритель по замеру. **Проверить на RTX: там CUDA скорее всего быстрее** |
| Сборка выбирается по compute capability | CUDA 13 не поддерживает Pascal и старше: CC ≥ 7.5 и драйвер ≥ CUDA 13 → `cuda13`; CC ≥ 5.0 и драйвер ≥ 12.4 → `cuda12`; иначе `vulkan`. Для torch: GTX 10xx → cu126, RTX → cu130 (требование ComfyUI) |
| ComfyUI — скрытый движок, а не конкурент | он поддерживает почти всё; в режиме «Профи» его граф можно открыть как есть |
| Файлы моделей не копируем, храним путь | у человека уже могут быть десятки гигабайт в LM Studio или Ollama |
| Формат pickle (`.ckpt`, `.pt`) не разбираем | в нём может быть вредоносный код. Предлагаем найти ту же модель в safetensors или GGUF |
| Движки в Job Object с kill-on-close | закрылась или упала Ollivo — Windows сама убивает движки, видеопамять не течёт |
| Автообновление сделано в фазе 1, а не в конце | иначе первые тестеры застрянут на старой версии навсегда |
| Обновления и манифест движков — в S3 Timeweb, запасной адрес обновлений — выпуск на GitHub | как в ClipVault; GitHub — если S3 недоступен (с 0.1.0). Движки обновляются **отдельно от программы**. Каталог моделей в S3 не выносим: люди сами качают модели откуда хотят и подключают к программе, встроенной подборки хватает |
| История разговоров — JSON-файлы, не SQLite | разговоров сотни, а не миллионы. Поиск по всем — перебором файлов: 500 разговоров (23 МБ) за 0,2 с, из них 0,11 — чтение. SQLite — только если объёмы вырастут на порядок или понадобится поиск по смыслу |
| Прокси только из настроек Ollivo | системный прокси Windows не подхватываем (`no_proxy()`) — чтобы поведение было предсказуемым |
| Подписи кода (SmartScreen) нет | Microsoft бесплатно не выдаёт, денег пока нет. Обходимся инструкцией на сайте, публикацией SHA256 и проверкой на VirusTotal. Упаковщики exe не используем — они повышают риск ложных срабатываний |
| Пресеты вместо чисел, числа только в ядре | человек не знает слов «температура» и «top-p»; «Профи» позже перебьёт их своими. Направление перевода решает ядро — маленькие модели условий в промпте не выполняют |
| Ошибки переводит ядро, окно рисует кнопки | один сбой одинаково объяснён на всех экранах; сырой текст не выбрасываем — он нужен тому, кто будет помогать |
| Интерфейс и комментарии в коде — по-русски | продукт русскоязычный; технические термины в простом режиме запрещены |

Товарный знак: в WIPO Ollivo есть только в Индии, классы 6 и 20 (мебель, фурнитура) —
с софтом (классы 9 и 42) не пересекается. Роспатент ещё не проверяли.

## 5. Что сделано и как

### Фаза 0 — разведка (закрыта)

Прототипы в `spikes/`. Тестовый ПК: GTX 1080 8 ГБ (Pascal, CC 6.1), драйвер 582.66 (CUDA 13.0), ОЗУ 32 ГБ.

Главные замеры:

- llama-server, Qwen2.5 3B Q4_K_M: CUDA 12 — 52 ток/с, Vulkan — **81 ток/с**, CUDA 13 — **падает на Pascal**.
- Скачивание с HuggingFace: 1 поток — 0,75 МБ/с, 8 потоков через Range — **5,7 МБ/с** (в 7,6 раза быстрее).
- SHA256 файла HF отдаёт в заголовке `X-Linked-ETag` — целостность проверяется без манифеста.
- uv + Python 3.12 + torch cu126 + ComfyUI: venv **5,2 ГБ**, torch из локального файла ставится за 93 с
  вместо ~40 минут через pip. SD 1.5 512² — 9 с, пик памяти +3,1 ГБ (прогноз совпал).
  SDXL 1024² — 60 с, пик +6,5 ГБ, работает впритык без замедления.
- На Pascal ComfyUI держит веса в fp16, удвоения памяти нет.

### Фаза 1 — каркас и установка (закрыта)

- **Железо** (`hardware.rs`): NVML — имя, видеопамять, CC, пропускная способность, драйвер, ОЗУ,
  несъёмные диски, флаг `profile_risky` (кириллица или пробел в профиле).
- **Менеджер загрузок** (`download.rs`): запрос первого байта без перенаправлений → размер,
  поддержка Range, SHA256; куски по 8 МБ в 8 соединений, готовые куски в `<файл>.part.json`,
  пауза = отмена, продолжение с того же места; 5 повторов с растущей паузой, затем следующее
  зеркало; битый хеш → стираем и качаем заново. **Только HTTP/1.1** — см. грабли.
- **Манифест движков** (`manifest.rs`, `manifest/engines.json`): llama.cpp b11081, три сборки,
  SHA256 из дайджестов GitHub. Выигрывает манифест с бо́льшим `revision`.
- **Установка движков** (`engines.rs`): архив → SHA256 → распаковка во временную папку → переименование,
  так оборванная установка не выглядит готовой. «Починить» сверяет файлы с `ollivo.files.json`
  и переустанавливает битое; перед починкой llama.cpp модель останавливается — файлы заняты.
- **Прокси и секреты** (`net.rs`): HTTP / SOCKS5 (`socks5h` — DNS через прокси), кнопка «Проверить»
  проходит цепочку прокси → HuggingFace → GitHub с понятной ошибкой на каждом шаге.
- **Мастер первого запуска** (`setup.rs`, `pages/Wizard.tsx`): проверки ПК (VC++ с 0.1 не нужен — `vcrt.rs`)
  через официальный установщик Microsoft (единственное место с UAC), выбор диска, проверка сети и движка.
- **Экран установки** (`components/InstallScreen.tsx`): шаги, время словами, пауза, автоповтор при
  обрыве сети, прогресс на кнопке в панели задач. В фазе 4 туда же пойдут Python, torch и ComfyUI.
- **Менеджер процессов** (`process.rs`): запуск без консоли, логи в файл, ожидание готовности по HTTP,
  все движки в одном Job Object.
- **Автообновление** (`update.rs`, `scripts/publish-update.ps1`): каналы stable и beta,
  цепочка 0.0.1 → 0.0.2 **проверена вживую** — нашло, скачало, поставило, перезапустилось.

### Фаза 2 — чат с текстовыми моделями (закрыта)

- **Библиотека моделей** (`library.rs`, `probe.rs`, `gguf.rs`, `safetensors.rs`): файл добавляется
  кнопкой или перетаскиванием, тип и «светофор» определяются по заголовку. Разобранный заголовок
  кешируется в `models.json`, «светофор» считается заново каждый раз — он зависит от свободной памяти.
  Файл изменился → перечитываем, пропал → помечаем «нет на месте», из списка не выкидываем.
- **Подхват уже скачанного** (`scan.rs`): папки LM Studio, Ollama, ComfyUI и своя. У Ollama файлы
  названы по хешу — понятное имя берём из его манифестов. Файлы не копируются.
- **Каталог** (`catalog.rs`, `manifest/catalog.json`, `pages/Catalog.tsx`): встроенная подборка
  из 8 моделей (Qwen3.5 2B/4B/9B/27B/35B-A3B, Gemma 4 E4B, LFM2.5 2.6B, Qwen3 Coder 30B A3B)
  с точными размерами и SHA256 — открывается без сети. Плюс живой поиск по HuggingFace,
  хеши оттуда же (`lfs.oid`). Отсеиваются служебные файлы (`mmproj`, `mtp`, `dflash`), модели,
  разрезанные на части, и оригиналы без сжатия. Сжатие читается из имени файла и переводится
  на человеческий: Q4 — «обычный выбор», Q2 — «отвечает заметно хуже».
- **«Светофор» до скачивания** (`probe::rough`): размеров модели без заголовка не узнать, поэтому
  память разговора и буферы берутся долей от весов (700 МБ + ⅛ размера). У моделей «из частей» (MoE)
  скорость считается по работающей части — иначе 35B выглядела бы вчетверо медленнее, чем она есть.
  Меньше трёх токенов в секунду — так и пишем, до скачивания, а не после.
- **Чат** (`llm.rs`, `pages/Chat.tsx`, `components/Answer.tsx`): стриминг по SSE, «Остановить»
  обрывает за 0,3 с, разметка через markdown-it, код отдельной карточкой с «Копировать»,
  «Ответить заново». Присланный моделью HTML не исполняется, ссылки уходят в браузер.
- **История разговоров** (`chats.rs`): файл на разговор, список в меню, продолжение и удаление.
  Поиск над списком: все слова запроса, регистр и «ё/е» не важны, под названием — кусок реплики
  с подсветкой. Строчные буквы для кириллицы и латиницы считаются напрямую — общий
  `to_lowercase` съедал три четверти времени.
- **Понятные ошибки** (`trouble.rs`, `components/ProblemCard.tsx`): ядро переводит лог движка
  в «что случилось, что делать» и набор кнопок, сырой текст — под «Подробности». Образцы —
  из нарочно вызванных сбоев: нехватка видеопамяти, обрезанный и испорченный файл, незнакомое
  семейство, длинный разговор, нет DLL. «Запустить экономнее» — до трёх ступеней: вдвое меньше
  память разговора и на четверть меньше слоёв на видеокарте; проверено вживую.
- **Лицензия в карточке** (`components/License.tsx`): при скачивании из каталога лицензия
  и репозиторий со страницы HF запоминаются в библиотеке — в заголовке GGUF её часто нет.
  Показывается одной фразой: свободная / можно с условиями автора / только для себя /
  свои условия, для несвободных — ссылка на страницу модели.
- **Роль и манера ответа** (`presets.rs`): под полем ввода — роль (помощник, переводчик,
  программист) и «Точнее · Обычно · Креативнее». Окно шлёт id, промпт и температуру
  подставляет ядро; роль и манера хранятся в разговоре. Направление перевода решает ядро:
  Qwen2.5 3B с условием «с русского — на английский, иначе — на русский» не справилась.
- **Автонастройка запуска** (`plan` в `lib.rs`): слои на видеокарту и размер контекста ядро считает
  перед самым стартом — когда прошлая модель уже выгружена, иначе видеопамять выглядит занятой.
  Окно шлёт только путь к файлу. Ручные числа в запросе перебивают расчёт — задел под «Профи».

### Как обновить значок

Исходники — `src-tauri/icons/app-icon.svg` (знак) и `app-icon-small.svg` (он же жирнее, для 16 и 24 px).
После правки: `python scripts/make-icons.py` — пересоберёт все PNG и `icon.ico`. Логотип сайта
`site/logo.svg` — копия `app-icon.svg`, его поправить тем же движением.

### Как обновлять подборку каталога

Размеры и хеши в `manifest/catalog.json` сняты через API HuggingFace. Чтобы добавить модель
или обновить версии: взять `https://huggingface.co/api/models/<repo>/tree/main?recursive=true`,
оттуда `size` и `lfs.oid` (это и есть SHA256), и записать в `files`. Проверить
`cargo test catalog::tests::bundled_is_valid` — он сверяет длину хешей и что имя файла
сходится с заявленным сжатием. Подборка обновляется только с выпуском программы — это решение:
модели люди качают сами, откуда хотят.

## 7. Грабли (каждая стоила времени)

- ⚠️ **CUDA 13 не работает на Pascal.** GTX 10xx и старше — только CUDA 12 или Vulkan.
- ⚠️ **HTTP/2 убивает многопоточную загрузку:** reqwest пускает все потоки через одно соединение,
  и 8 потоков дают те же 0,6 МБ/с. Клиент загрузок принудительно на HTTP/1.1.
- ⚠️ **BOM ломает автообновление.** `Set-Content -Encoding utf8` в Windows PowerShell пишет BOM,
  а плагин updater такой JSON не разбирает — в окне это выглядит как «не получилось связаться
  с сервером обновлений». Описание версии пишем `[IO.File]::WriteAllText` с `UTF8Encoding($false)`.
- ⚠️ **Windows не хранит пустую переменную окружения** (`$env:X = ''` удаляет её), поэтому ключ
  подписи без пароля не годится для автоматической сборки: tauri спрашивает пароль прямо в консоли,
  перенаправление ввода не помогает. Ключ сделан с паролем, пароль — в диспетчере учётных данных.
- ⚠️ **llama.cpp и whisper.cpp требуют VC++ Runtime** (`msvcp140`, `vcruntime140`, `vcruntime140_1`),
  llama.cpp ещё и `vulkan-1.dll`. VC++ программа кладёт рядом с движком сама (`vcrt.rs`), но только если
  в системе его нет или он старее: своя копия рядом с exe выигрывает у системной всегда, даже у более новой.
- ⚠️ **В выдаче поиска HF нет поля `gated`** — без `expand[]=gated` все модели выглядели
  закрытыми. `expand` заменяет набор полей целиком: остальные (downloads, likes, tags) — тоже явно.
- ⚠️ **Qwen вставляет китайские слова** в русский текст даже при температуре 0. Переводчику
  иероглифы запрещены грамматикой llama.cpp (`presets::NO_CJK`), −7% скорости.
- ⚠️ **hf-mirror.com работает не из всех стран:** отсюда отвечает 308 на huggingface.co и для файлов,
  и для API. Поэтому токен разрешён и для huggingface.co, а проверка токена при таком перенаправлении
  спрашивает HF напрямую.
- ⚠️ **uv кладёт ярлык в `%USERPROFILE%\.local\bin`** — ровно туда, где кириллица в имени пользователя
  всё ломает. Запускать с `--no-bin` (или `UV_PYTHON_BIN_DIR` внутрь нашей папки).
- Первые ~15 секунд загрузки с GitHub байтов нет (перенаправления) — на экране «Подключаюсь к серверу…».
- Vite по умолчанию слушал только `::1`, а Tauri ждал IPv4 → dev-сервер привязан к `127.0.0.1`.
- `keyring` 4 сменил API — взята версия 3 (`windows-native`).
- `nvidia-smi` под полной нагрузкой иногда не отвечает — память читать через NVML и терпеть ошибки.
- В curl из Git Bash портится кириллица — проверять через Python или Rust.
- Думающие модели (Qwen3.5) пишут рассуждения в `reasoning_content`, а не в `content`:
  если читать только ответ, окно минуту «молчит».
- Qwen-VL со зрением без `--image-min-tokens 1024` путает мелкое на картинке («42» → «4»).
- Qwen3.5 2B после ответа инструмента пишет ответ внутри рассуждений и не закрывает их —
  ответ пустой. Со второго запроса цикла `enable_thinking = false`.
- Маленькие модели пишут путь с именем самой папки проекта и читают один файл по кругу —
  `Tools::path` убирает имя папки, повторное чтение получает короткую пометку.
- Служебную справку о прошлых действиях модель копирует как свой стиль: Qwen2.5 3B написала
  «[С файлами: удален notes.txt]», ничего не удалив. Справка — перед вопросом человека,
  а окно предупреждает, если слова модели об изменениях не подтверждены шагами.
- `Tools` (и «уже прочитан») — на один ответ. Общий набор на несколько ответов в тесте
  выглядел как «модель читает по кругу и не может править».
- CUDA-архив whisper.cpp без cuBLAS: `ggml-cuda.dll` молча не грузится, всё идёт на процессоре.
- whisper всегда считает окно в 30 с — короткой фразе нужен `-ac` по длине, иначе вдвое дольше.
- Сплошной 7z читается подряд: ненужный файл из архива надо дочитать до конца, иначе
  следующий начнётся с его хвоста (`engines::unpack_7z`).
- Голосовые Telegram — `.ogg`, но внутри Opus, а не Vorbis: whisper их не читает. Отличаем
  по `OpusHead` в начале файла.
- С `bundle.createUpdaterArtifacts` сборка без ключа подписи падает — CI из-за этого был
  красным четыре дня. В CI — `--config src-tauri/tauri.ci.conf.json`. Сборка без ключа
  оставляет рядом старый `.sig` — поэтому `publish-update -SkipBuild` подписывает заново.

## 8. Правила, которые стоит соблюдать

- **Язык:** интерфейс, комментарии в коде, коммиты и заметки — по-русски, коротко.
  В простом режиме нет технических терминов: не «квантизация Q4_K_M», а «обычный выбор:
  почти как оригинал, а места вдвое меньше».
- **Честность перед пользователем важнее красивых цифр.** Если модель будет отвечать по слову
  в секунду, это надо сказать до того, как он скачает десять гигабайт.
- **Секреты только в диспетчере учётных данных Windows.** В `settings.json`, в коде и в заметках —
  максимум имена переменных, никогда значения.
- **Имена, приходящие с чужого сервера, в файловые пути не пускать.** См. `model_dest` в `lib.rs`
  и тест `download_path_stays_inside_models_folder`.
- **Каждая фаза заканчивается проверкой на чистой машине** с кириллическим именем пользователя.
- **Тесты, которым нужна сеть или настоящие модели, помечаются `#[ignore]`** — обычный прогон
  должен работать офлайн и быстро.

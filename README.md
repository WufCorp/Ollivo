# Ollivo

Десктоп-программа для запуска локальных открытых ИИ-моделей на своём компьютере.
Установил, выбрал модель, начал разговор — без Python, Git и настройки CUDA.
Текст, картинки, звук и видео в одном окне; переписка не уходит в интернет.

Сайт: [ollivo.ru](https://ollivo.ru). Windows + NVIDIA, версия 0.0.2, в разработке.

## Что уже работает

- Мастер первого запуска: проверка компьютера и драйвера, установка библиотек
  Microsoft VC++, выбор диска, проверка интернета и прокси.
- Менеджер загрузок: несколько потоков, продолжение после обрыва, проверка
  контрольных сумм, запасные зеркала, пауза.
- Установка движка llama.cpp по манифесту с понятным экраном загрузки;
  кнопка «Починить» сверяет файлы и перекачивает испорченные.
- Запуск текстовых моделей (GGUF) и проверочный вопрос к модели.
  Движки живут в Job Object: закрылась программа — закрылись и они.
- Автообновление: каналы обычных и ранних версий, подпись обновлений.
- Библиотека моделей со «светофором» (пойдёт ли модель на вашем компьютере)
  и подхват того, что уже скачали LM Studio, Ollama или ComfyUI.
- Чат: ответ появляется по ходу, разметка и код с кнопкой «Копировать»,
  история разговоров, «Ответить заново». Слои и память разговора программа
  подбирает сама под вашу видеокарту.
- Каталог: подборка проверенных моделей и поиск по HuggingFace. У каждого
  варианта видно, сколько он весит, что значит его сжатие и пойдёт ли он
  на вашем компьютере; скачанное само попадает в библиотеку.

## Дальше

Голосовой ввод, вложения, генерация картинок через ComfyUI, режим «Профи».

## Как устроено

| Часть | Чем сделано |
| --- | --- |
| Оболочка | Tauri 2 + React + TypeScript |
| Ядро | Rust: железо (NVML), загрузки, манифест движков, запуск процессов |
| Текст и зрение | llama.cpp (`llama-server`), сборки Vulkan / CUDA 12 / CUDA 13 |
| Картинки и видео | ComfyUI + PyTorch, ставятся по требованию |
| Голос | whisper.cpp |

Сборка движков выбирается по видеокарте: у старых карт CUDA 13 не работает,
для них берётся CUDA 12, а для чата по умолчанию — лёгкая сборка Vulkan.

## Сборка из исходников

Нужны Node.js 22+ и Rust (стабильный).

```bash
npm install
npm run tauri dev     # запуск в режиме разработки
npm run tauri build   # установщик NSIS в src-tauri/target/release/bundle/nsis
```

Тесты ядра:

```bash
cargo test --manifest-path src-tauri/Cargo.toml
```

Тесты с настоящей сетью и моделями помечены `#[ignore]` и запускаются отдельно
ключом `--ignored`.

Выпуск новой версии — [RELEASE.md](RELEASE.md).

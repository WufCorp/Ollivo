# Ollivo

Десктоп-программа для запуска локальных открытых ИИ-моделей на своём компьютере.
Установил, выбрал модель, начал разговор — без Python, Git и настройки CUDA.
Текст, картинки, звук и видео в одном окне; переписка не уходит в интернет.

Сайт — папка [site/](site/), скоро на [ollivo.ru](https://ollivo.ru). Windows + NVIDIA,
ранняя версия, в разработке.

## Что уже работает

- Мастер первого запуска: проверка компьютера и драйвера, установка библиотек
  Microsoft VC++, выбор диска, проверка интернета и прокси.
- Модели — любые GGUF, откуда угодно: перетащите файл в окно, а уже скачанное
  в LM Studio, Ollama или ComfyUI программа подхватит сама, без копирования.
  Для тех, кто не знает, с чего начать, — подборка проверенных моделей и поиск по HuggingFace.
- «Светофор» до скачивания: пойдёт ли модель на этом компьютере и с какой скоростью —
  словами, в сравнении со скоростью чтения.
- Чат: ответ по ходу, разметка и код, история и поиск по разговорам, роли и манера ответа.
  Слои и память разговора программа подбирает сама; без дела модель освобождает видеокарту.
- Документы (PDF, DOCX, ODT, TXT, код), фото для моделей со зрением (в том числе WebP и HEIC),
  диктовка и расшифровка записей (MP3, M4A, голосовые Telegram, звук из видео).
- Папка проекта: модель читает, ищет и правит файлы в режимах «Вручную · Авто · План»,
  любое изменение можно вернуть.
- Понятные ошибки с кнопками и «Сообщить о проблеме» одной кнопкой.
- Движки ставятся и чинятся сами, программа обновляется сама (обновления подписаны).

## Как устроено

| Часть | Чем сделано |
| --- | --- |
| Оболочка | Tauri 2 + React + TypeScript |
| Ядро | Rust: железо (NVML), загрузки, манифест движков, запуск процессов |
| Текст и зрение | llama.cpp (`llama-server`), сборки Vulkan / CUDA 12 / CUDA 13 |
| Картинки и видео | ComfyUI + PyTorch, ставятся по требованию |
| Голос | whisper.cpp |

Сборка движков выбирается по видеокарте: у старых карт CUDA 13 не работает,
для них берётся CUDA 12, а для чата по умолчанию — лёгкая сборка Vulkan.

## Сборка из исходников

Нужны Node.js 22+ и Rust (стабильный).

```bash
npm install
npm run tauri dev     # запуск в режиме разработки
npm run tauri build   # установщик NSIS в src-tauri/target/release/bundle/nsis
```

Тесты ядра:

```bash
cargo test --manifest-path src-tauri/Cargo.toml
```

Тесты с настоящей сетью и моделями помечены `#[ignore]` и запускаются отдельно
ключом `--ignored`.

Выпуск новой версии — [RELEASE.md](RELEASE.md).

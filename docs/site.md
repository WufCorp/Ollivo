# Сайт

Одностраничник для людей, а не для разработчиков: что это, как начать, что умеет, приватность,
что дальше, как скачать, вопросы. Лежит в [site/](../site/), выкладывается на GitHub Pages
workflow [pages.yml](../.github/workflows/pages.yml) на каждый push в `main`, где менялся `site/`.

## Как устроен
- Один файл `index.html` со стилями и скриптом внутри, плюс `logo.svg`. Без сборки и зависимостей:
  правка текста — это правка одного файла.
- **Ни одного внешнего запроса, кроме API GitHub.** Шрифты системные (Segoe UI Variable на Windows —
  у целевой аудитории он есть), счётчиков и cookie нет. Программа обещает приватность — сайт
  не должен начинать знакомство с Google Fonts и метрикой.
- Кнопка «Скачать» спрашивает у API GitHub последний выпуск и ведёт прямо на `…setup.exe`,
  с версией, размером и SHA256 (поле `digest`, GitHub считает его сам). Выпуска нет — надпись
  «Первая сборка — скоро» и ссылка на страницу выпусков. GitHub недоступен или кончился лимит
  (60 запросов в час с одного адреса) — кнопка просто ведёт на страницу выпусков. Проверено на выложенном
  сайте: при исчерпанном лимите (403) кнопка — «Скачать для Windows» со ссылкой на выпуски.
- Светлая и тёмная тема — по настройке Windows. На телефоне без горизонтальной прокрутки
  (проверено на 375 px).

## Правила текста
- Только то, что уже работает. Будущее — в блоке «Что дальше» с номерами версий из [Плана](plan.md).
  Сделали фазу — перенести её из «Что дальше» в «Возможности».
- Цифры — настоящие. Карточки каталога на сайте — вывод `catalog::tests::real_picks --ignored`
  на GTX 1080 (2026-09-27); надписи кнопок и светофора — те же, что в программе.
- Без терминов, как в простом режиме программы.

## Поддержка проекта (донаты)
Boosty, ЮMoney и криптовалюта (USDT TRC20, TON, BTC). Всё берётся из одного файла
[site/support/support.json](../site/support/support.json); `node scripts/make-support.mjs` собирает из него:
- QR-коды и кнопки — `site/support/*.svg` (QR — библиотекой `qrcode` при сборке, а не на странице:
  сайт и GitHub показывают готовую картинку, внешних запросов нет);
- [DONATE.md](../DONATE.md) — страница на GitHub: кнопки, адреса в блоках кода (у них есть кнопка
  «скопировать»), QR, на что пойдут деньги, как помочь без денег;
- блок «Поддержать проект» в README между метками `support:start` / `support:end`;
- `.github/FUNDING.yml` — кнопка «Sponsor» на GitHub (Boosty и ЮMoney у GitHub нет среди площадок — ссылки `custom`).

Руками эти файлы не правим. Адреса хранятся в одном месте: подмену видно в одном диффе.
В программе адресов нет — только ссылка на страницу поддержки.

Скрипт сверяет контрольную сумму каждого адреса (TRON и BTC — base58check, TON — CRC16) и не собирает
страницу, если хоть одна буква потерялась при копировании; проверено порчей одного символа в каждом адресе.
Кошельки — адреса пополнения Bybit (2026-09-27): монеты зачисляются на биржевой счёт.

# Сайт

Одностраничник для людей, а не для разработчиков: что это, как начать, что умеет, приватность,
что дальше, как скачать, вопросы. Лежит в [site/](../site/), выкладывается на GitHub Pages
workflow [pages.yml](../.github/workflows/pages.yml) на каждый push в `main`, где менялся `site/`.

## Как устроен
- Один файл `index.html` со стилями и скриптом внутри, плюс `logo.svg`. Без сборки и зависимостей:
  правка текста — это правка одного файла.
- **Ни одного внешнего запроса, кроме API GitHub.** Шрифты системные (Segoe UI Variable на Windows —
  у целевой аудитории он есть), счётчиков и cookie нет. Программа обещает приватность — сайт
  не должен начинать знакомство с Google Fonts и метрикой.
- Кнопка «Скачать» спрашивает у API GitHub последний выпуск и ведёт прямо на `…setup.exe`,
  с версией, размером и SHA256 (поле `digest`, GitHub считает его сам). Выпуска нет — надпись
  «Первая сборка — скоро» и ссылка на страницу выпусков. GitHub недоступен или кончился лимит
  (60 запросов в час с одного адреса) — кнопка просто ведёт на страницу выпусков.
- Светлая и тёмная тема — по настройке Windows. На телефоне без горизонтальной прокрутки
  (проверено на 375 px).

## Правила текста
- Только то, что уже работает. Будущее — в блоке «Что дальше» с номерами версий из [Плана](plan.md).
  Сделали фазу — перенести её из «Что дальше» в «Возможности».
- Цифры — настоящие. Карточки каталога на сайте — вывод `catalog::tests::real_picks --ignored`
  на GTX 1080 (2026-09-27); надписи кнопок и светофора — те же, что в программе.
- Без терминов, как в простом режиме программы.

## Посмотреть у себя
Любой статический сервер, например:

```bash
python -m http.server 5178 --directory site --bind 127.0.0.1
```

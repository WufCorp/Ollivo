# Настройки программы

Что должно быть в настройках. ⭐ — обязательно к MVP (фаза 2), остальное — по фазам.
Секреты (пароль прокси, токен HF) — только в диспетчере учётных данных Windows, не в `settings.json`.

## Для всех (простой режим)

### Сеть
- [x] ⭐ **Прокси** — HTTP / SOCKS5, адрес, порт, логин и пароль, кнопка «Проверить» (сам прокси → HF → GitHub). Сделано в фазе 1.
- [x] ⭐ **Зеркало HuggingFace** — «Основной сайт / hf-mirror.com / своё». ⚠️ hf-mirror.com не из всех стран работает: отсюда перенаправляет на huggingface.co.
- [x] ⭐ **Токен HuggingFace** — для закрытых моделей, кнопка «Проверить токен». Уходит только на HF и хост зеркала.
- [ ] Ограничение скорости загрузки — чтобы не забивать интернет всей семье.
- [ ] Прокси передаётся в uv/pip, ComfyUI и Tauri updater (переменные `HTTP(S)_PROXY`, `ALL_PROXY`).

### Место на диске
- [ ] ⭐ **Папка программы** — где лежат движки и модели; перенос на другой диск с переносом файлов.
- [ ] ⭐ Сколько занято: модели, движки, кэш, картинки; кнопка «Очистить кэш и недокачанное».

### Память и видеокарта
- [ ] ⭐ **Выгружать модель через N минут простоя** — освобождает видеопамять для игр и других программ. По умолчанию 10 мин.
- [ ] Не запускать тяжёлое, пока играет полноэкранная игра (позже).

### Внешний вид и запуск
- [ ] ⭐ Тема: светлая / тёмная / как в Windows.
- [ ] Язык интерфейса (RU / EN), размер текста.
- [ ] Запускать вместе с Windows; закрытие окна — в трей или выход.
- [ ] Уведомления: загрузка закончилась, картинка готова.

### Обновления
- [ ] ⭐ Обновлять программу: автоматически / спрашивать. Канал: стабильный / бета.
- [ ] Обновлять движки и каталог моделей по манифесту — отдельно от программы.

### Голос

### Приватность и данные

- [ ] Отчёты об ошибках: выключено по умолчанию, спрашивать при сбое.

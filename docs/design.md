# Оформление «Приборы»

С 2026-09-27. До этого окно было черновым: синяя кнопка по умолчанию, серый фон, эмодзи
вместо значков, варианты моделей — по четыре строки мелкого серого текста. Сайт при этом
уже был в оливковой палитре со своим значком — человек скачивал с оливкового сайта
безликую программу.

Выбирали из трёх вариантов (макеты делали отдельной страницей, в репозиторий не клали):
«Олива» (палитра сайта поверх привычного чата), «Книга» (ответы шрифтом с засечками,
линейки вместо карточек), «Приборы». Выбран третий.

## Суть
Главное обещание Ollivo — узнать, пойдёт ли модель, **до** того, как скачал её. «Приборы»
делают это видимым: числа про память и скорость не спрятаны в текст, а нарисованы.

- **Шкала «влезет ли»** (`components/Fit.tsx`) — у каждого варианта в каталоге и у каждой
  модели в «Моделях»: полоса «сколько видеопамяти займёт из свободной», цветом «светофора».
  Подпись — та же фраза ядра «нужно ~…, свободно …», отдельной строкой её больше нет.
  Числа дают поля `need` и `room` у `Verdict` (`probe.rs`); без видеокарты они `null`
  и шкалы нет. Тест `catalog::tests::gauge_agrees_with_light`: зелёная помещается,
  не помещающаяся не зелёная.
- **Строка состояния** внизу окна (`components/StatusBar.tsx`): какая модель и в каком
  состоянии, видеопамять кубиками (на 8 ГБ — по гигабайту), сколько разговора помнит,
  свободная оперативная память. Видеопамять опрашивается раз в 10 с (NVML каждый раз
  открывается заново) и сразу при смене состояния модели; в свёрнутом окне — не опрашивается.
  Узко — второстепенное прячется (container query по ширине рабочей области: в чате её
  сужает колонка разговоров).
- **Каркас**: узкая панель значков слева (72 px) вместо меню словами, колонка разговоров
  только в чате — с группами «Сегодня / Вчера / На этой неделе / Раньше», кнопка «Отчёт»
  внизу панели открывает «Сообщить о проблеме».
- **Чат на всю область**, как в мессенджере: свои вопросы справа, ответы слева без пузыря,
  подпись «Модель» над ответом. Раньше чат был колонкой 780 px посередине, и на широком
  экране по бокам пустовало по 400 px. Строку ответа держим ~80 знаков (`max-width: 82ch`):
  длиннее глаз теряет начало следующей строки, а место справа занимают вопросы.
  Поле ввода одним блоком во всю ширину: скрепка, папка, микрофон значками, роль, манера,
  «Отправить». Имя модели — в строке состояния.
- **Шапка разговора**: название, ярлычок папки проекта («Переезд · Вручную»), кнопки панели.

## Панель справа от чата (`components/ChatPanel.tsx`)
Открывается кнопками «Разговор» и «Файлы» в шапке, повторное нажатие закрывает. Открытая
вкладка помнится между запусками (`localStorage`, ключ `ollivo.chat-panel`). Если чату
остаётся меньше 860 px (container query `chatpage`), панель выезжает поверх чата, а не
сжимает его.

- **Разговор** — сколько памяти разговора занято шкалой: «1 из 12 страниц», жёлтая с 60 %,
  красная с 90 %. Раньше человек узнавал об этом, только когда модель забыла начало или не
  влез документ. Считается той же прикидкой, что и проверка «документ не поместится»
  (`usedTokens` в `Chat.tsx`), страницы — `pageCount` в `words.ts` с тем же округлением,
  что у «помнит около N страниц», иначе панель и строка состояния называли разные числа.
  Там же модель, скорость последнего ответа, «Сменить модель», «Выгрузить» и роли
  карточками с объяснением; пока вкладка открыта, выпадающего списка ролей под полем нет.
- **Файлы** — вложения разговора («к вопросу» — ещё не отправлен), папка проекта с поиском
  (от 12 файлов), режим «Вручную · Авто · План», «Сменить» и «Убрать», шаги модели
  с «Вернуть как было». Метки у файлов: «приложен», «изменён», «прочитан».
  **Нажатие на файл = выбор после «@»**: в тексте появляется `@путь`, сам файл
  прикладывается к вопросу — модель получит его, даже если сама файлы открывать не умеет.
  Выбрали папку — панель сама открывается на «Файлах». Строка папки над перепиской убрана.
- **Картинки** — третья вкладка, появится вместе с картинкой из чата (фаза 4). Пустую
  вкладку заранее не делаем.

## Токены
Всё оформление — `src/App.css`, цвета только переменными в `:root`.

| | Тёмная (по умолчанию) | Светлая |
|---|---|---|
| Фон | `#0d0f09` | `#eef0e7` |
| Панель значков | `#090a06` | `#e2e5d8` |
| Текст / приглушённый | `#e5e8da` / `#9a9f88` | `#141a0b` / `#5d634f` |
| Акцент (кнопки) | `#a8c64f` | `#4d7414` |
| Светофор | `#95c95a` `#e2b449` `#e3765f` | `#4f8f2a` `#b8841a` `#b8483a` |

Глубина на тёмной — шагом прозрачности белого (`--panel` 3,5 %, `--panel-2` 6,5 %)
и рамкой `inset box-shadow`, а не тенями: тень на тёмном не видна.

Шрифты только системные — программа ничего не тянет из сети, CSP это и не пустит:
**Segoe UI Variable** для текста, **Bahnschrift** для заголовков, подписей и чисел
(есть в каждой Windows 10/11, узкий, «приборный»). Значки — свои SVG линией
(`components/Icon.tsx`): эмодзи Windows рисует цветными картинками, рядом с кнопками
они выглядят чужими.

Движение: нажатая кнопка чуть сжимается (`scale(.96)`) — наведение есть только у мыши;
шкалы заполняются при появлении (0,7 с); запись с микрофона — пульсирующая точка.
`prefers-reduced-motion` всё это выключает.

## Тема — своя, а не как в Windows
«Настройки → Оформление → Цвет окна»: тёмное (по умолчанию) или светлое. Варианта
«как в Windows» больше нет: оформление задумано тёмным, светлое — по желанию,
и от системы оно не зависит (решение владельца 2026-09-27). «system» в `settings.json`
от прошлых версий читается как тёмная — тест `settings::tests` проверяет.
Механика прежняя: ядро ставит тему окну (`set_theme`), WebView2 передаёт её в
`prefers-color-scheme`. Окно создаётся тёмным (`tauri.conf.json`: `theme`, `backgroundColor`),
чтобы при запуске не мигало белым.

## Проверено
В окне 2026-09-27 (dev-сборка, GTX 1080, qwen2.5 0.5B): чат, каталог со шкалами, «Модели»,
«Компьютер», «Настройки», окно отчёта; тёмная и светлая, переключение из настроек
сразу после «Сохранить»; окно 1100×720 и на весь экран 1920×1080.

Чат на всю ширину и панель — в окне 2026-09-27 (qwen2.5 3B, тестовая папка из трёх файлов):
нажатие на файл в панели дало `@notes.txt` в поле и плашку файла, модель ответила по нему;
«1 из 12 страниц» совпадает со строкой состояния; метки «прочитан» / «приложен»;
в окне 1100×720 панель выезжает поверх чата и закрывается крестиком.

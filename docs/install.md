# Установка и зависимости

Цель: человек без Python, Git, CUDA ставит программу и через несколько минут пользуется.
Системный Python/Git/CUDA **не используем вообще** — всё своё, внутри папки программы.

## Схема
1. **Установщик (~50–100 МБ):** само приложение (Tauri) + `uv.exe`. Без прав администратора, на пользователя.
2. **Мастер первого запуска:** проверка железа и драйвера → выбор диска → докачка компонентов с прогрессом.
3. **Компоненты ставятся по задаче, а не все сразу:**
   - Чат (текст/vision): llama.cpp, готовая сборка с CUDA из релизов GitHub. Python не нужен → чат работает через ~5 минут.
   - Картинки/видео: Python (через `uv python install`) + venv + torch cu12x + ComfyUI из zip закреплённой версии (без Git).
   - Голос: whisper.cpp или faster-whisper; ffmpeg — статическая сборка.

## Проверки мастера
- Драйвер NVIDIA (NVML / nvidia-smi): старый → понятное сообщение и ссылка на обновление. CUDA Toolkit не нужен — рантайм внутри колёс torch и сборок llama.cpp.
- VC++ Redistributable: проверка по реестру, если нет — тихая установка (единственное место с UAC).
- Место на диске: показать сколько нужно заранее (torch ~3 ГБ + модели).
- **Путь без кириллицы и пробелов, короткий** (`C:\Ollivo`, или `<диск>:\Ollivo` — диск выбирает пользователь). Кириллическое имя пользователя ломает Python-инструменты, MAX_PATH=260 — длинные пути ломают pip. AppData не использовать, если в пути не-ASCII.

## Надёжность
- Манифест версий (JSON на нашем сервере): проверенные связки компонентов, URL, SHA256. Обновления компонентов — по манифесту.
- Докачка с продолжением, проверка хешей, повторы, зеркала (HF/GitHub/PyPI бывают медленными или недоступны).
- Кнопка «Починить»: сверка файлов с манифестом и перекачка битого.
- Модели хранятся отдельно от движков; при удалении спросить, оставить ли их.
- Подпись кода (SmartScreen, антивирусы); исключение для Defender предложить, не делать молча.
- Позже: офлайн-установщик.

## Экран установки (UX для новичка)
Принцип: человек всегда понимает, что качается, зачем, сколько осталось и что всё не зависло.
- **До старта — предупреждение:** «Скачаем 4,1 ГБ, займёт 9 ГБ, ~10 минут на вашей скорости». Кнопки [Начать] [Позже].
- **Список шагов** с состояниями ✓ / идёт / ждёт. У каждого человеческое название, размер и одна фраза «зачем»
  (PyTorch → «Инструменты для видеокарты», ComfyUI → «Движок картинок»). Технические имена только в «Подробнее».
- **Общий прогресс + прогресс шага:** ГБ из ГБ, скорость, оставшееся время словами («примерно 6 минут»).
- **Никогда не «висит»:** распаковка и установка тоже с прогрессом («Распаковываем 12 000 файлов»), живая анимация.
- **Результат проверки ПК — позитивно:** «RTX 3060, 12 ГБ — отлично подходит».
- **Не блокировать:** пока качается движок картинок, чат уже работает. Можно свернуть; прогресс на панели задач Windows и в трее, уведомление по готовности.
- **Пауза / продолжить,** можно закрыть программу и докачать потом.
- **Подсказки во время ожидания:** что можно будет сделать («напиши в чате „нарисуй…“»).
- **Ошибки простыми словами + кнопка действия** («Пропал интернет — продолжим сами, когда он появится»).
- **«Подробнее»** раскрывает настоящий лог (для любопытных и профи).

# Прототипы фазы 0

Одноразовые проверки рисков перед написанием программы. Код отсюда потом переносится в ядро.

## model-probe
Определяет тип модели по заголовку файла (GGUF, safetensors, ggml Whisper) и считает «светофор» под железо этого ПК.
Веса не читаются — хватает первых мегабайт файла.

```
cargo run --release -- [--json] [--vram ГБ] [--ram ГБ] <файлы...>
```
`--vram` и `--ram` подменяют железо, чтобы проверить модель на «чужом» ПК.

## llama-server
`llama-server/chat.py <порт> [вопрос]` — потоковый запрос к `llama-server` (OpenAI API), замер времени до первого токена и скорости.
Сборки llama.cpp и модели лежат вне репозитория, в `D:\gui_Ai_lab`. Результаты — в Obsidian, заметка «Фаза 0».

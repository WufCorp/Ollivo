Первая публичная сборка Ollivo — программы, которая запускает ИИ-модели прямо на вашем компьютере.
Переписка никуда не уходит, интернет нужен только чтобы скачать модель.

**Что умеет**
- Разговор с моделью: ответ появляется по ходу, история и поиск по разговорам, манера «Точнее · Обычно · Креативнее».
- Любые модели GGUF: перетащите файл в окно, а скачанное в LM Studio, Ollama или ComfyUI программа найдёт сама.
  Для начала — подборка проверенных моделей и поиск по HuggingFace.
- До скачивания видно, пойдёт ли модель на вашем компьютере и как быстро будет отвечать.
- Документы (PDF, DOCX, ODT, TXT), фото для моделей, которые видят картинки, диктовка и расшифровка записей,
  в том числе голосовых из Telegram.
- Папка проекта: модель читает и правит файлы, любое изменение можно вернуть.
- Понятные ошибки с кнопками и «Сообщить о проблеме» — одной кнопкой.

**Что нужно**: Windows и видеокарта NVIDIA. Прав администратора программа не просит.

Это ранняя версия. Что-то не работает — нажмите в программе «Сообщить о проблеме», это очень поможет.

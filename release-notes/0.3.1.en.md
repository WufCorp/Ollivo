Fixes from the first feedback, and the “Images” section.

**Fixed**
- The chat no longer loses questions. If you switched to another tab while the model was answering,
  the question disappeared and the answer was appended to the previous one. Now the answer keeps going
  in the background, and the question is saved as soon as you send it.
- Server graphics cards (Tesla and others in a mode without graphics): the regular engine couldn't see them
  and silently computed on the processor. Such a card now gets the CUDA engine.
- If the engine crashes on start, you can install another build — CUDA — on the “Computer” page.
- In “Auto” mode the model no longer deletes files without asking: deleting only happens with your permission.

**What's new**
- Download speed limit: “Settings → Network”. A model downloads, and the internet stays usable for everyone else.
- The model for other programs: “Settings → For other programs”. SillyTavern, qwen-code and others
  can talk to the model in Ollivo — from this computer and only with the key. Instructions are right there.
- A model on another computer or server: “Models → A model on another computer or server…”.
  Ollivo becomes a window to Ollama, LM Studio or your own server — that computer does the work.
- The “Images” section (first version): draws pictures from a description on your NVIDIA graphics card.
  The image engine downloads on first visit, about 5 GB. Descriptions work best in English.
- A “Report” can now go to the Ollivo group in Telegram or MAX — not only to GitHub.
- The model in the app now always runs with a key: other programs on the computer
  can't use it without your permission.

Something wrong? Click “Report” at the bottom left — it really helps.

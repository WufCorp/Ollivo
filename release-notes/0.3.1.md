Исправления по первым отзывам и раздел «Картинки».

**Исправлено**
- Чат больше не теряет вопросы. Если во время ответа перейти на другую вкладку, вопрос пропадал,
  а ответ дописывался к прошлому. Теперь ответ идёт и в фоне, а вопрос сохраняется сразу при отправке.
- Серверные видеокарты (Tesla и другие в режиме без графики): обычный движок их не видел и молча
  считал на процессоре. Теперь для такой карты ставится движок CUDA.
- Если движок падает при запуске, на «Компьютере» можно поставить другую сборку — CUDA.
- В режиме «Авто» модель больше не удаляет файлы без спроса: удаление — только с вашего разрешения.

**Что нового**
- Ограничение скорости загрузок: «Настройки → Сеть». Модель качается, а интернет остаётся остальным.
- Модель для других программ: «Настройки → Для других программ». SillyTavern, qwen-code и другие
  смогут разговаривать с моделью из Ollivo — с этого компьютера и только по ключу. Инструкция — там же.
- Модель на другом компьютере или сервере: «Модели → Модель на другом компьютере или сервере…».
  Ollivo станет окном к Ollama, LM Studio или своему серверу — считать будет тот компьютер.
- Раздел «Картинки» (первая версия): рисует картинки по описанию на вашей видеокарте NVIDIA.
  Движок для картинок скачивается при первом заходе, около 5 ГБ. Описание лучше писать по-английски.
- «Отчёт» можно отправить в группу Ollivo в Telegram или MAX — не только на GitHub.
- Модель в программе теперь всегда работает с ключом: другие программы на компьютере
  без вашего разрешения к ней не обратятся.

Что-то не так — нажмите «Отчёт» внизу слева, это очень поможет.
